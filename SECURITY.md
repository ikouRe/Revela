# Politique de sécurité

## Signaler une faille

Merci de ne pas ouvrir d'issue publique.

Utilise le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**.

Décris le problème, comment le reproduire et son impact possible.
